# Stage 0 Project Definition

## Game Concept

プレイヤーは家に取り憑いた幽霊。

怪奇現象を起こして住人を怖がらせ、最終的に家から追い出す。

ただし怪奇現象を連打すれば勝てるゲームにはしない。

ゲームの中心は **恐怖** と **慣れ**。

同じ怪奇現象を繰り返すほど住人は慣れ、効果が落ちる。

## Core Loop

```text
観察
↓
仮説
↓
怪奇現象
↓
住人の反応
↓
恐怖・慣れの変化
↓
次の手を考える
```

## Player Experience

プレイヤーに感じてほしいのは、単純な爽快感だけではない。

- 「こいつ、これが苦手なのか」
- 「さっきの現象には慣れてきたな」
- 「じゃあ次はこっちを試そう」

という、幽霊側から人間を攻略している感覚を重視する。

## Genre Direction

**幽霊 × 箱庭 × 観察 × 軽い戦略／パズル × 育成シミュレーション**

プレイヤー自身を怖がらせるホラーゲームではない。

## Kairosoft-inspired Principles

カイロソフト作品のUI・キャラクターデザイン・ドット絵そのものをコピーしない。

参考にするのは、ゲームループ・成長・発見の気持ちよさ。

三本柱:

1. 眺めているだけでも楽しい住人生活
2. 組み合わせを発見する怪奇現象システム
3. 小さな地縛霊から伝説の心霊屋敷へ成長する発展感

## Important Difference from Large-scale Management Games

このゲームは、大量NPCを半自動で管理するゲームにはしない。

怖がらせる対象の住人は、現時点では多くても10人程度を想定する。

理由:

- 怪奇現象を仕掛けるタイミングが重なりすぎると判断負荷が高くなる
- 一人ひとりの生活を観察する面白さが薄れる
- 管理ゲームではなく、少人数への介入の手触りを重視したい

ただし、最終的な適正人数は固定しない。
Stage 1以降のテストプレイで決定する。

## Combination Design

将来的な重要要素:

**怪奇現象 × 場所 × タイミング × 住人**

住人はプレイヤーが直接動かさない。
自律的に生活し、その隙を狙って怪奇現象を仕掛ける。

## Goals

短期目標:

- 住人を退去させる

長期目標:

- 家を強い心霊スポットへ成長させる

## Tone

怖すぎない。

かわいい・コミカル寄りにしつつ、軽いゾワッと感は残す。

血まみれのホラー表現を中心にはしない。

## Stage 1 Core Fun Hypothesis

> 住人の生活を観察し、「今だ」と思った瞬間に適切な怪奇現象を仕掛けることが面白い。さらに、同じ怪奇現象への「慣れ」によって次の一手を考えることが面白い。

Stage 1では、この仮説だけを最優先で検証する。
