# External Playtest Guide

## For the facilitator

This guide is for the person running the test.

### What to say before play

Use only this explanation:

> You are a ghost. Observe the resident and use three paranormal phenomena to scare them out of the house. Try to figure out when each phenomenon works well.

You may explain the controls, but do not explain the hidden timing rules or optimal strategy.

### Controls you may explain

- Click the three action buttons
- Keyboard `1 / 2 / 3` can also trigger them
- Pause is available

### Do not explain before or during the first run

- which phenomenon matches TV / sleep / doorway movement
- exact Opportunity timing
- GOOD / MISTIMED thresholds
- exact Adaptation numbers or recovery delay
- why the resident chooses a specific next activity

### During the first run

Do not coach unless the tester cannot operate the game.

Write down spontaneous comments such as:

- "I think this works when..."
- "Why did that fail?"
- "I should wait for..."
- "I'm just pressing everything"

Also note whether the tester watches the resident before pressing.

### After the first run

Ask the questions in `EXTERNAL_PLAYTEST_SURVEY.md`.

If the tester voluntarily wants another run, allow it before explaining any hidden rules. Record whether their strategy changes.

### Important

The purpose is not to help the tester succeed. The purpose is to see whether the game itself teaches the core loop.
